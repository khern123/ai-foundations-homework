Test 3 · Problem 9 usability feature

Normalized catalogue search

The storefront search box uses the normalized, deduplicated search engine. Typing "1/4 zip" finds all 11 quarter-zips, even though the catalogue names them "… 1 4 Zip". Plain keyword matching would miss them. The live result count reads "11 results for “1/4 zip”".

✓ 11 results, which equals the 11 quarter-zips in the catalogue, with no duplicates.
